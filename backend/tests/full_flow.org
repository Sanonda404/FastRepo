* Cloning
Someone not logged in will try to clone both public and private repositories. Public will pass, private will not
#+begin_src shell :exports both
  git -C /tmp clone http://$host/alice/test-public
#+end_src

#+RESULTS:

#+begin_src shell :exports both
  git -C /tmp clone http://$host/alice/test-private 2>&1
#+end_src

#+RESULTS:
: Cloning into 'test-private'...
: fatal: could not read Username for 'http://127.0.0.1:8000': No such device or address

But logging in with alice will successfully clone it. Alice will create an empty commit in main.
#+begin_src shell :exports both
  git -C /tmp clone http://alice:alice123@$host/alice/test-private
  git -C /tmp/test-private config user.name "alice"
  git -C /tmp/test-private config user.email "alice123@test.com"
  git -C /tmp/test-private commit --allow-empty -m "First Commmit"
  git -C /tmp/test-private push origin main
#+end_src

#+RESULTS:
: [main 2caa0c2] First Commmit

* Adding Collaborators
Now bob will be added to collaborators and then he can clone too.

#+begin_src http :exports both
  POST /collaborators/alice/test-private
  Authorization: Bearer ${aliceToken}
  Content-Type: application/json

  {
      "identifier" : "bob",
      "role": "write"
  }
#+end_src

#+RESULTS:

:   "id": 1,
:   "repository_id": 2,
:   "user_id": 2,
:   "username": "bob",
:   "email": "bob123@test.com",
:   "role": "write"
: }

Now clone it as bob
#+begin_src shell :exports both
  git -C /tmp clone http://bob:bob123@$host/alice/test-private test-private-bob
#+end_src

#+RESULTS:

Now bob creates branch, commit and pushes
#+begin_src shell :exports both
  git -C /tmp/test-private-bob config user.name "bob"
  git -C /tmp/test-private-bob config user.email "bob123@test.com"
  git -C /tmp/test-private-bob checkout -b bob-branch
  echo "Hello World" > /tmp/test-private-bob/foo.txt
  git -C /tmp/test-private-bob add foo.txt && git -C /tmp/test-private-bob commit -m "Test commit from bob"
  git -C /tmp/test-private-bob push origin bob-branch
#+end_src

#+RESULTS:
: [bob-branch 0cc333b] Test commit from bob
:  1 file changed, 1 insertion(+)
:  create mode 100644 foo.txt
